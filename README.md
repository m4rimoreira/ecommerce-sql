# 🛒 E-commerce Analytics com SQL

Análise de vendas de um e-commerce fictício usando **SQL (SQLite)** e Python para visualização.

## 🎯 Objetivo
Responder perguntas de negócio a partir de um banco relacional com 4 tabelas:
1. Faturamento por categoria
2. Top 10 clientes por valor gasto
3. Ticket médio por estado
4. Taxa de recompra (clientes recorrentes vs. ocasionais)
5. Evolução do faturamento mensal

## 🛠 Tecnologias
- SQL (SQLite)
- Python 3.10+
- Pandas
- Matplotlib
